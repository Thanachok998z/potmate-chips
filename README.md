# PotMate — ระบบนับชิปสมมติ 2 ผู้เล่น

เว็บนี้ใช้ร่วมกันผ่านเซิร์ฟเวอร์เดียว ผู้เล่นสร้างห้อง ส่งรหัส 8 ตัวให้อีกคน และเล่นจากคนละอุปกรณ์ได้ ชิปเป็นแต้มสมมติ ไม่มีระบบไพ่หรือเงินจริง

## เริ่มใช้งานบนเครื่อง

ต้องมี Node.js 20 ขึ้นไป

```sh
npm start
```

เปิด `http://localhost:3000` ผู้เล่น 1 สร้างห้อง ผู้เล่น 2 เปิดเว็บเดียวกันบนอีกอุปกรณ์แล้วกรอกรหัส หากต้องใช้ผ่านอินเทอร์เน็ต ให้นำแอปขึ้นโฮสต์ Node.js ที่มี HTTPS

มี `Dockerfile` สำหรับโฮสต์ที่รับ Docker โดยต้องผูก volume ถาวรเข้าที่ `/app/data` และตรวจสุขภาพที่ `/health`

## ทางเผยแพร่ที่เตรียมไว้: Render แผนฟรี

ไฟล์ `render.yaml` กำหนดเว็บเซอร์วิสแผนฟรีใน Singapore และตรวจสุขภาพที่ `/health` โดยรัน `npm test` ระหว่าง build ก่อนเปิดเว็บ ต้องนำโฟลเดอร์นี้ขึ้น Git repository ให้ `render.yaml` อยู่ที่รากของ repository ก่อน

ถ้าใช้ GitHub ผ่านหน้าเว็บ ให้สร้าง repository ใหม่ แล้วเลือก **Add file → Upload files** อัปโหลด *เนื้อหาข้างใน* โฟลเดอร์ `potmate-live` โดยให้ `package.json`, `server.mjs`, `render.yaml`, `public/` และ `test/` อยู่ที่ระดับบนสุดของ repository จากนั้นส่งลิงก์ repository มาเพื่อให้ตรวจและเชื่อม Render ก่อนเปิดใช้

แผนฟรีไม่มีดิสก์ถาวร ห้อง ชิป และประวัติจะหายเมื่อบริการพัก รีสตาร์ต หรือเผยแพร่ใหม่ และหน้าเว็บอาจต้องรอประมาณหนึ่งนาทีเมื่อกลับมาเปิดหลังพัก เหมาะสำหรับเล่นสั้น ๆ กับเพื่อน หากต้องการเก็บห้องข้ามวันให้ย้ายไปแผนที่มีดิสก์หรือฐานข้อมูลภายหลัง

```sh
npm test
```

ชุดทดสอบตรวจ Bet → Call → เริ่มรอบเบ็ตใหม่โดย pot ไม่ถูกจ่าย, การสะสม pot หลายรอบ, ค่าธรรมเนียม 0.5% ตอนยืนยันผู้ชนะ, การกดยืนยันซ้ำ และการกู้ข้อมูลหลังรีสตาร์ตเซิร์ฟเวอร์

## กติกาที่ทำงานอยู่

1. ลากหรือแตะชิปของตนเอง ชิปจะเข้ากองกลางทันทีและนับเป็น Bet; ถ้ายอดที่วางในรอบเบ็ตนี้สูงกว่าอีกฝ่าย จะนับเป็น Raise อัตโนมัติ
2. ฝ่ายที่ต้องตอบ Bet/Raise กด Call ระบบเติมยอดส่วนต่างจาก balance แล้วเริ่มรอบเบ็ตใหม่ โดย pot ยังคงสะสมอยู่
3. ทั้งสองฝ่ายสามารถเริ่ม Bet ในรอบเบ็ตใหม่ได้ ไม่ได้บังคับลำดับตามตำแหน่งดีลเลอร์ เพราะเว็บไม่ได้เล่นไพ่
4. ปุ่ม **All-in** วางยอดคงเหลือทั้งหมดได้ แม้ยอดเหลือเป็นเศษต่ำกว่า 1k ถ้าอีกฝ่าย Call ไม่ถึง ระบบคืนชิปส่วนที่ไม่มีการ Call ให้ผู้วางอัตโนมัติ เมื่อการ Call จบแล้วจะไม่มี Bet เพิ่มในตาเล่นนั้น
5. ผู้เล่นหมอบได้เมื่อ pot มีชิป หากมี Bet ที่ยังไม่ถูก Call ระบบคืนส่วนที่เกินให้ผู้วางก่อน ผู้ที่ไม่หมอบกด “I'm Win” เพื่อขอรับ pot อีกฝ่ายต้องยืนยัน
6. หากยังมี Bet/Raise ที่รอ Call ต้อง Call หรือหมอบก่อนจึงจะขอจบตาเล่นได้
7. กด **ฉันเสมอ** เพื่อให้ทั้งสองฝ่ายได้รับยอดสุทธิครึ่งหนึ่ง โดยอีกฝ่ายต้องยืนยันเช่นกัน ถ้าแบ่งแล้วเหลือเศษ 1 ชิป ระบบสลับให้ผู้เล่น 1 ในตาเล่นคี่และผู้เล่น 2 ในตาเล่นคู่
8. เมื่อยืนยัน ระบบหักค่าธรรมเนียม `floor(pot × 0.005)` หนึ่งครั้ง เพิ่มยอดสุทธิให้ผู้ชนะหรือแบ่งให้ทั้งสองฝ่าย แล้วเริ่มตาเล่นใหม่
9. ผู้ขอผลถอนคำขอได้ อีกฝ่ายปฏิเสธคำขอได้ หากยังตกลงผลกันไม่ได้ pot จะค้างอยู่

## การใช้งานจริงบนโฮสต์

- รัน **หนึ่งอินสแตนซ์** ของแอปนี้ เพราะข้อมูลเก็บในไฟล์ JSON และการล็อกรายการทำภายในโปรเซสเดียว
- หากต้องการเก็บห้องข้ามการรีสตาร์ต ให้กำหนด `DATA_DIR` ไปยังดิสก์ถาวรที่สำรองข้อมูลได้; บนแผนฟรีข้อมูลในโฟลเดอร์ค่าเริ่มต้น `data` เป็นข้อมูลชั่วคราว
- ตั้ง `PORT` ตามโฮสต์ และให้โฮสต์เปิด HTTPS ด้านหน้าแอป ห้ามเปิดผ่าน HTTP สาธารณะ เพราะเบราว์เซอร์เก็บสิทธิ์ผู้เล่นในเครื่อง
- ไม่ลบข้อมูลเบราว์เซอร์ระหว่างเล่น แต่ละอุปกรณ์จะจำสิทธิ์กลับเข้าห้องเดิมหลังรีเฟรช หากกด “ออกจากหน้านี้” สิทธิ์บนเครื่องจะถูกลบและเข้าที่นั่งเดิมไม่ได้
- ไม่เปิดหลาย replica โดยใช้ไฟล์ข้อมูลร่วมกัน หากต้องการหลายเครื่องเซิร์ฟเวอร์ต้องเปลี่ยนส่วนจัดเก็บเป็นฐานข้อมูลที่รองรับธุรกรรม

## ข้อจำกัดที่ยังต้องตกลงก่อนใช้เป็นกติกาโป๊กเกอร์เต็มรูปแบบ

เว็บเป็นตัวช่วยบันทึกชิป ไม่ตัดสินไพ่หรือบังคับกติกาการเดิมพันทุกกรณี ยังไม่มี Check, การยกเลิกรายการวางผิดโดยทั้งสองฝ่ายตกลงกัน, หรือการกู้สิทธิ์ผู้เล่นหลังล้างข้อมูลเบราว์เซอร์ ต้องตกลงเรื่องเหล่านี้ก่อนใช้กับเกมที่ต้องการกติกาโป๊กเกอร์ครบถ้วน

## สถานะ

ซอร์สโค้ดและชุดทดสอบเตรียมไว้แล้ว แต่สภาพแวดล้อมในแชทนี้ยังรันโปรเซสและเปิดเบราว์เซอร์เพื่อตรวจจริงไม่ได้ จึงยังไม่ยืนยันว่าทดสอบผ่าน และยังไม่ได้ขึ้นโฮสต์
