# PotMate — ระบบนับชิปสมมติ 2–4 ผู้เล่น

เว็บนี้ใช้ร่วมกันผ่านเซิร์ฟเวอร์เดียว ผู้เล่นสร้างห้อง ส่งรหัส 8 ตัวให้เพื่อนอีก 1–3 คน และเล่นจากคนละอุปกรณ์ได้ ชิปเป็นแต้มสมมติ ไม่มีระบบไพ่หรือเงินจริง

## เริ่มใช้งานบนเครื่อง

ต้องมี Node.js 20 ขึ้นไป

```sh
npm start
```

เปิด `http://localhost:3000` คนแรกสร้างห้อง แล้วผู้เล่นคนอื่นเปิดเว็บเดียวกันบนอุปกรณ์ของตนและกรอกรหัส ห้องเริ่มเล่นได้ตั้งแต่ 2 คน และรับได้สูงสุด 4 คน ผู้เล่นเพิ่มได้เมื่อจบตาเล่นและกองกลางว่าง หากต้องใช้ผ่านอินเทอร์เน็ต ให้นำแอปขึ้นโฮสต์ Node.js ที่มี HTTPS

มี `Dockerfile` สำหรับโฮสต์ที่รับ Docker โดยต้องผูก volume ถาวรเข้าที่ `/app/data` และตรวจสุขภาพที่ `/health`

## ทางเผยแพร่ที่เตรียมไว้: Render แผนฟรี

ไฟล์ `render.yaml` กำหนดเว็บเซอร์วิสแผนฟรีใน Singapore และตรวจสุขภาพที่ `/health` โดยรัน `npm test` ระหว่าง build ก่อนเปิดเว็บ ต้องนำโฟลเดอร์นี้ขึ้น Git repository ให้ `render.yaml` อยู่ที่รากของ repository ก่อน

ถ้าใช้ GitHub ผ่านหน้าเว็บ ให้สร้าง repository ใหม่ แล้วเลือก **Add file → Upload files** อัปโหลด *เนื้อหาข้างใน* โฟลเดอร์ `potmate-live` โดยให้ `package.json`, `server.mjs`, `render.yaml`, `public/` และ `test/` อยู่ที่ระดับบนสุดของ repository จากนั้นส่งลิงก์ repository มาเพื่อให้ตรวจและเชื่อม Render ก่อนเปิดใช้

แผนฟรีไม่มีดิสก์ถาวร ห้อง ชิป และประวัติจะหายเมื่อบริการพัก รีสตาร์ต หรือเผยแพร่ใหม่ และหน้าเว็บอาจต้องรอประมาณหนึ่งนาทีเมื่อกลับมาเปิดหลังพัก เหมาะสำหรับเล่นสั้น ๆ กับเพื่อน หากต้องการเก็บห้องข้ามวันให้ย้ายไปแผนที่มีดิสก์หรือฐานข้อมูลภายหลัง

```sh
npm test
```

ชุดทดสอบตรวจ Bet/Raise/Call สี่คน, All-in ที่มีกองหลักและกองย่อย, เสมอเฉพาะผู้เล่นที่เลือก, การยืนยันผลทุกคน, ค่าธรรมเนียม 0.5%, การกดยืนยันซ้ำ และการกู้ข้อมูลหลังรีสตาร์ตเซิร์ฟเวอร์

## กติกาที่ทำงานอยู่

1. ลากหรือแตะชิปของตนเอง ชิปจะเข้ากองกลางทันทีและนับเป็น Bet; ถ้ายอดที่วางในรอบเบ็ตนี้สูงกว่ายอดสูงสุด จะนับเป็น Raise อัตโนมัติ
2. ผู้เล่นที่ต้องตอบ Bet/Raise จะผลัดกันตามลำดับที่นั่ง กด Call เพื่อเติมยอดส่วนต่าง หรือวางชิปเพิ่มเพื่อ Raise หรือหมอบ เมื่อทุกคนตอบแล้วจะเริ่มรอบเบ็ตใหม่ โดย pot ยังคงสะสมอยู่
3. ในรอบเบ็ตใหม่ ผู้เล่นที่ยังมีชิปคนใดก็เริ่ม Bet ได้ ไม่บังคับตำแหน่งดีลเลอร์ เพราะเว็บไม่ได้เล่นไพ่
   หากไม่ลงชิป กด **Check** แล้วกด **Next** เพื่อส่งสิทธิ์ Bet/Check ให้ผู้เล่นคนถัดไป เมื่อทุกคน Check ครบรอบ ระบบเริ่มรอบเบ็ตใหม่โดยกองกลางยังอยู่
4. ปุ่ม **All-in** วางยอดคงเหลือทั้งหมดได้ แม้ต่ำกว่า 1k ผู้เล่นที่ชิปยังเหลือสามารถเบ็ตกองย่อยต่อกันได้ ระบบแยกกองหลักและกองย่อยตามยอดที่แต่ละคนลงจริง และคืนยอดสูงสุดที่ไม่มีใคร Call
5. หมอบได้เมื่อถึงตาตอบ Bet/Raise ผู้เล่นที่หมอบไม่มีสิทธิ์รับชิปจากกองนั้น
6. หากยังมี Bet/Raise ที่รอตอบ ต้อง Call หรือหมอบก่อนจึงจะเสนอผลได้
7. กด **I'm Win** หรือ **ฉันเสมอ** แล้วเลือกผู้รับชิปในแต่ละกอง เสมอแบ่งเฉพาะชื่อที่เลือกในกองนั้น เศษชิปจะแจกตามลำดับที่นั่งซึ่งหมุนไปในแต่ละตาเล่น
8. ผู้เล่นทุกคนในห้อง รวมถึงคนที่หมอบ ต้องยืนยันผลก่อน ระบบจึงหักค่าธรรมเนียม `floor(pot × 0.005)` ครั้งเดียว แจกยอดสุทธิและเริ่มตาเล่นใหม่
9. ผู้เสนอผลถอนคำขอได้ ผู้อื่นปฏิเสธได้ หากยังตกลงผลกันไม่ได้ pot จะค้างอยู่

## การใช้งานจริงบนโฮสต์

- รัน **หนึ่งอินสแตนซ์** ของแอปนี้ เพราะข้อมูลเก็บในไฟล์ JSON และการล็อกรายการทำภายในโปรเซสเดียว
- หากต้องการเก็บห้องข้ามการรีสตาร์ต ให้กำหนด `DATA_DIR` ไปยังดิสก์ถาวรที่สำรองข้อมูลได้; บนแผนฟรีข้อมูลในโฟลเดอร์ค่าเริ่มต้น `data` เป็นข้อมูลชั่วคราว
- ตั้ง `PORT` ตามโฮสต์ และให้โฮสต์เปิด HTTPS ด้านหน้าแอป ห้ามเปิดผ่าน HTTP สาธารณะ เพราะเบราว์เซอร์เก็บสิทธิ์ผู้เล่นในเครื่อง
- ไม่ลบข้อมูลเบราว์เซอร์ระหว่างเล่น แต่ละอุปกรณ์จะจำสิทธิ์กลับเข้าห้องเดิมหลังรีเฟรช หากกด “ออกจากหน้านี้” สิทธิ์บนเครื่องจะถูกลบและเข้าที่นั่งเดิมไม่ได้
- ไม่เปิดหลาย replica โดยใช้ไฟล์ข้อมูลร่วมกัน หากต้องการหลายเครื่องเซิร์ฟเวอร์ต้องเปลี่ยนส่วนจัดเก็บเป็นฐานข้อมูลที่รองรับธุรกรรม

## ข้อจำกัดที่ยังต้องตกลงก่อนใช้เป็นกติกาโป๊กเกอร์เต็มรูปแบบ

เว็บเป็นตัวช่วยบันทึกชิป ไม่ตัดสินไพ่หรือบังคับกติกาการเดิมพันทุกกรณี ยังไม่มี Check, การยกเลิกรายการวางผิดโดยทุกคนตกลงกัน, หรือการกู้สิทธิ์ผู้เล่นหลังล้างข้อมูลเบราว์เซอร์ ต้องตกลงเรื่องเหล่านี้ก่อนใช้กับเกมที่ต้องการกติกาโป๊กเกอร์ครบถ้วน
